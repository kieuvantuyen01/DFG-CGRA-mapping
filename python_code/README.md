# SAT-Based Hierarchical Mapping for DFG-CGRA

Dự án này triển khai phương pháp phân cấp (hierarchical approach) cho bài toán ánh xạ đồ thị luồng dữ liệu (DFG) lên mảng khả cấu hình thô (CGRA) sử dụng SAT solving.

## Yêu cầu

- Python 3.9+
- PySAT
- NetworkX (cho phương pháp phân cấp)
- Pandas, Matplotlib (cho benchmark)

## Cài đặt

```bash
pip install python-sat networkx pandas matplotlib
